6. Package a clean evidence bundle (`DR3_REPLAY_EVIDENCE.zip`) and SHA-256 checksums (`DR3_REPLAY_SHA256SUMS.txt`).

## 5. Authentic Post-Training Gradient Diagnostic

Unlike `scripts/probe_csam_gradient_paths.py` (which used synthetic representations for initialization analysis), `scripts/probe_csam_trained_checkpoint.py` performs an authentic post-training diagnostic:

1. **Real Representations:**
   - Encodes a fixed batch of 16 authentic AAPD Train documents with the trained BERT model.
   - Encodes all 54 label definitions with the trained BERT model.
2. **Computational Graph Retention:**
   - Sets model to `eval()` mode (freezing dropout).
   - Retains gradients at $h_T$ (`h_T.retain_grad()`) and $h_L$ (`h_L.retain_grad()`).
3. **Algebraic Logit Decomposition:**
   - Document-dependent term: $\text{doc\_term}_{b, i} = \alpha_{b, i} (W h_{L, i})$.
   - Static SA term: $\text{sa\_term}_i = W (A h_L)_i$ (zero in `L2_NO_SA`).
   - Scalar bias term: $b$.
   - Reconstructed logits: $\text{reconstructed} = \text{doc\_term} + \text{sa\_term} + b$.
   - Verifies maximum absolute reconstruction error $< 10^{-4}$.
4. **Controlled Backward Pass:**
   - Evaluates Focal Loss and standard BCE on the identical logits and ground truth.
   - Calls `loss.backward(retain_graph=True)`.
   - **Zero optimizer step:** No optimizer parameters are updated.
5. **Measurements Recorded:**
   - $\|\nabla_{h_T} \mathcal{L}\|$, $\|\nabla_{h_L} \mathcal{L}\|$, $\|\nabla_W \mathcal{L}\|$, $\|\nabla_b \mathcal{L}\|$.
   - Gradient finiteness and ratios.
   - Attention entropy and max attention.
   - Component magnitudes and variances across documents and labels.
